# campaign-lift-did

転職サイト新規顧客獲得キャンペーン（2025/8/1–8/31）のジオ実験を、差分の差分法（DID）で
**統計モデルとして推定・検定**する分析パイプライン。

配信する県（32）と配信しない県（15）を事前に分けたうえで実施された都道府県単位の2群比較。
「配信しなかった場合と比べてエントリーが何件増えたか」を、誤差の幅つきで推定する。

## 実行

```sh
pip install -r requirements.txt
python run_did.py       # 推定・検定 → output/tables/ に CSV、要点は標準出力
python run_figures.py   # 作図       → output/figures/ に PNG
```

生成物はリポジトリに含めていない（スクリプトを実行すれば再現できるため）。

## データ

| ファイル | 内容 |
|---|---|
| `data/raw/log_data_unpivoted.csv` | 日次 × 都道府県 × 性別 × 年代 × 前職種 のエントリー数・面談実施数（134,605行、2025/5/1–8/31） |
| `data/raw/prefectures_control_test.csv` | 都道府県ごとの配信群（Test=32）／非配信群（Control=15）の割当 |
| `data/raw/prefecture_master.csv` | 都道府県マスタ（JISコード・表記の対応） |

生ログは **エントリーが1件以上発生した組み合わせしか行を持たない疎なデータ**で、
0件のセルは行として存在しない（取りうる52万セルに対し実在13万行＝充足率25.9%）。
県×日へ集約する際は必ず0埋めを行う。`data_prep.build_panel` が行数を検証して落ちる。


## 手法

主分析は **PPML（ポアソン疑似最尤）**。

```
E[Y_it] = exp(alpha_i + gamma_t + beta * treat_i * post_t)
```

`exp(beta) - 1` がリフト率。カウントデータであり、県の規模が30倍の幅（494〜15,107件）を
持つため乗法モデルを採る。PPMLは分布の仮定が誤っていても beta を一致推定する。

### 設計上の判断

**固定効果は点推定に対して冗長。** 対数を取れば「県ごとに変化率を見る」ことと
「県固定効果を入れる」ことは同じ操作であり、さらにバランスドパネルでは日付固定効果も
群間の引き算で相殺される。実際に PPML の beta は群合計の対数比の差と
`1e-15` の精度で一致する（`models.check_fe_redundancy` で検証）。

それでもモデルとして推定するのは、推論の枠組みを統一するため、
イベントスタディやセグメント別に拡張するため、重み付けを明示的に選ぶため。

**過分散はない。** 県×日の生の分散/平均は44.2だが、その大半は県の規模差であり
固定効果が吸収する。固定効果適用後の Pearson 分散は 0.06、NB2 の alpha 推定値は負。
負の二項回帰は不要で、alpha を決め打ちすると推定が歪む（`models.dispersion_diagnostics`）。

### 誤差評価：県クラスタだけでは足りない

誤差には2つの源泉がある。

| 源泉 | 捉える方法 | 本データでの大きさ |
|---|---|---|
| (a) どの県が配信対象になったか | 並べ替え検定・県クラスタロバストSE | ±0.09 pt |
| (b) ある時期に両群を非対称に揺らす全国的なショック | 事前期間のプラセボ推定 | **±0.67 pt** |

(b) は (a) より1桁大きい。県クラスタは「同じ県の日次データが独立でない」ことは扱えるが、
「ある週に両群を非対称に揺らす共通ショック」は誤差として数えない。

これは推定結果からも確認できる。イベントスタディで配信前の週次効果を見ると
`-2.5%` から `+3.1%` の範囲でばらついており、県クラスタロバストの信頼区間（±0.3pt程度）
では説明できない。事前期間に偽の配信期間（31日）を置いて同じ推定を繰り返すと、
介入がないにもかかわらず最大 `+2.1%` の見かけの効果が生じる。

したがって**報告する信頼区間は (b) を基準に置く**（`inference.headline_estimate`）。
p値は割当の無作為化に基づく並べ替え検定を用いる。

## 結果

| 項目 | 値 |
|---|---|
| リフト率 | **+2.81%**　95%CI [+1.46%, +4.17%] |
| 増分エントリー数 | **+726 件**　95%CI [+383, +1,063] 件 |
| p値 | **0.0001**（並べ替え検定10,000回、同等以上の差は0回） |
| 面談実施数のリフト率 | +2.52%　95%CI [+0.49%, +4.60%] |
| 面談実施率 | 配信群 39.77%→39.80%、非配信群 39.60%→39.75%（質の劣化なし） |

配信32県の変化率は `+2.93%` 〜 `+4.95%`、非配信15県は `+0.66%` 〜 `+1.12%` で
**分布が完全に分離**している（重なり0組）。

### 「完全に分離している」は単独では効果の証拠にならない

月次で見ると、**配信前の6月にも対前月変化率の分布が完全に分離する**
（配信群 `+4.15%` 〜 `+6.95%` / 非配信群 `+2.71%` 〜 `+3.24%`、群平均の差 `+2.33 pt`）。
7月は逆に `-1.36 pt` と縮む。

原因は群内のばらつきの小ささにある。県別の対前月変化率の群内標準偏差は
非配信群 0.15 pt・配信群 0.80 pt しかなく、群単位でまとまって上下する。
そのため群×時点の共通ショックが少しでも乗れば、分布は容易に分離する。

したがって分離の有無は判定材料にならず、**差の大きさを時系列の揺らぎと比べる**必要がある。
プラセボ基準の sd 0.67 pt に対し実測は 2.81 pt（z = 4.2）で、この比較では効果は支持される。

### 既往キャンペーンは両群に非対称に効いていた

事前期間92日のうち46日が既往3キャンペーンの配信期間にあたる。
その期間の群比は 0.9876、キャンペーンのない期間は 0.9941 で、**0.65 pt の差**がある
（3キャンペーンとも同じ向き）。既往キャンペーンの地域構成が均等でなかった可能性がある。

ベースラインの取り方を変えた感度分析：

| ベースライン | リフト率 | 増分件数 |
|---|---|---|
| 事前期間すべて（92日）※採用 | +2.81% | +726 件 |
| 既往キャンペーンのない日のみ（46日） | +2.48% | +642 件 |
| 既往キャンペーン期間のみ（46日） | +3.15% | +812 件 |

振れ幅は ±0.34 pt で信頼区間（±1.35 pt）の内側に収まるため結論は変わらないが、
既往キャンペーンの実際の配信地域はクライアントに確認すべき事項として残る。

## セグメント別の効果（探索的）

属性ごとにDIDを推定し、誤差もセグメントごとに週ブロック・ブートストラップで測り直す
（`models.segment_effects`）。セグメントによって群×時点ショックの大きさが違うため、
全体の標準誤差を使い回すことはできない。

16セグメントの探索的な多重比較なので、BH法でFDRを調整したq値で判定する。

| 分類 | セグメント | 8月構成比 | リフト率 | 95%CI | q値(BH) | 増分件数 |
|---|---|---|---|---|---|---|
| 性別 | **女性** | 44.8% | **+4.20%** | +2.08 〜 +6.35 | **0.0016** | +482 |
| 性別 | 男性 | 55.2% | +1.70% | −1.02 〜 +4.48 | 0.465 | +243 |
| 年代 | **40歳代** | 27.1% | **+5.47%** | +2.29 〜 +8.76 | **0.0024** | +377 |
| 年代 | 30歳代 | 29.9% | +3.44% | +0.07 〜 +6.93 | 0.189 | +266 |
| 年代 | 20歳代 | 22.2% | +0.63% | −4.84 〜 +6.42 | 0.947 | +37 |
| 年代 | 50歳代 | 15.0% | −0.11% | −3.43 〜 +3.33 | 0.947 | −4 |
| 前職種 | 販売・サービス | 10.0% | +6.60% | +0.75 〜 +12.78 | 0.130 | +165 |
| 前職種 | 医療・福祉 | 10.0% | −0.24% | −4.81 〜 +4.54 | 0.947 | −6 |

（全16セグメントは `output/tables/segment_effects.csv`）

**調整後も0と区別できるのは女性と40歳代の2つだけ**。他は方向こそ揃うが誤差に埋もれる。
各次元の増分件数の合計は全体の +726件 と一致する（723／726／725）。

性別×年代の補助分析では、女性30歳代 `+6.65%`、女性40歳代 `+5.49%`、男性40歳代 `+5.44%` が
上位に並び、**効果は性別というより30〜40代に集中している**。20歳代・50歳代はほぼ0。

50歳代と医療・福祉がほぼ0であることは、効果が全セグメントに一様ではないことを意味する。
配信のターゲティング設定・クリエイティブ訴求と整合するかはクライアントに確認が必要で、
整合するなら「広告が原因」であることの傍証になる。

## 未解決の制約

- **消化金額が未受領**のため、増分CPA・ROIは算出できない。算定式と感度分析表のみ提示している
- データが8/31で終了しており、**配信後の残存効果を観測できない**
- 媒体・メニュー別の内訳が取得できないため、どの配信面が効いたかは分からない
- 全国外挿（+1,458件/月）は「非配信15県にも同率で効く」という強い仮定に立つ
